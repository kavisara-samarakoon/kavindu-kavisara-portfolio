The portfolio is focused on my career direction as an aspiring **Cybersecurity Analyst and Network Engineer**, while also showing my full-stack development, systems, cloud, and project-building skills.

> No public deployment is currently listed. A live URL will be added only after the portfolio is properly deployed.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kavisara-samarakoon/kavindu-kavisara-portfolio.git
```

### 2. Open the project folder

```bash
cd kavindu-kavisara-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local development URL:

```text
http://localhost:3000
```
